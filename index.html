ColorFLUX: A Structure-Color Decoupling Framework for Old Photo Colorization

CVPR 2026 Highlight 🎉

Reviving faded historical photographs with structure-preserving FLUX colorization, visual semantic prompts, and progressive color-preference optimization.

Overview

Old photos need more than generic colorization.

Old photos often contain faded brightness, altered hues, scratches, blur, and other degradations that differ from modern image distributions. ColorFLUX addresses this domain gap with a FLUX-based framework that decouples structure preservation from color restoration, enabling faithful geometry and plausible, modern colors.

The framework introduces visual semantic prompts to extract fine-grained information directly from old photos, and uses progressive Direct Preference Optimization to learn coarse-to-fine color preferences for richer saturation, contrast, and brightness without sacrificing realism.

Challenge

Fading creates a difficult color prior gap.

Existing restoration models can remove noise, blur, and scratches, but faded grayscale photos still provide weak or biased chromatic evidence. ColorFLUX restores color by separately learning structure consistency, basic color semantics, and fine color preference adjustment.

Method

Structure-color decoupling, then preference-aligned fine color.

01

Structure Consistency Training

ControlNet injects grayscale structure into FLUX while frozen visual color prompts encourage the model to learn geometry instead of entangled color shortcuts.

02

Basic Color Learning

A Redux-based visual semantic prompt extractor is fine-tuned with flow matching and feature distillation, replacing brittle text prompts with image-grounded semantics.

03

Progressive DPO

Color preference pairs move from strong augmentations to subtle ones, teaching the model to recover vivid modern colors from faded old-photo inputs.
